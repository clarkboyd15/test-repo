- Runs free in your Google account
- Can send emails, read calendar, access Sheets
- Runs on a schedule (daily, weekly, etc.)
- Takes 5-15 mins to set up

For HubSpot integration:
- Need your HubSpot API key (Settings → Integrations → API key)
- Script calls HubSpot API → formats data → emails you

## Quick Wins You Can Do Today

### In Gmail
1. **Filters for receipts:** Auto-label and skip inbox
   - Search: `from:(stripe OR amazon OR paypal)`
   - Create filter → Apply label "Receipts" → Skip inbox

2. **Canned responses:** Pre-written replies for common emails
   - Settings → Advanced → Enable Templates
   - Compose → Write template → Save as template

### In Google Calendar
1. **Recurring focus blocks:** Create repeating "Focus Time" events
2. **Working hours:** Settings → Working hours → Set your availability

### In HubSpot
1. **Saved views:** Create "Deals closing this week" and "Stale deals" views
2. **Email notifications:** Settings → Notifications → Get emailed on deal activity
