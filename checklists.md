## Rabbithole Exit Checklist

*Use when you notice you've drifted*

```
Time noticed: _______
What I was supposed to be doing: _______________
What I drifted into: _______________

☐ Is this my #1 priority today?
   Yes → Continue (set 25-min timer)
   No → Stop

☐ Will this matter in a week?
   Yes → Add to parking lot, schedule time
   No → Stop now

☐ Am I the only one who can do this?
   Yes → Consider if it's truly urgent
   No → Stop, delegate, or drop

☐ Captured the rabbithole in parking lot?
   Note: _______________________________

☐ Returned to original task?
   ☐ Set 25-min timer
   ☐ Started working

Time lost: ____ mins
Pattern: (morning/afternoon/after meetings/when tired)
___________________________________
```

## Emergency / Crisis Checklist

*When everything feels urgent*

```
☐ STOP. Take 3 breaths.

☐ List everything that feels urgent:
  1. _______________________________
  2. _______________________________
  3. _______________________________
  4. _______________________________
  5. _______________________________

☐ For each, ask: "What's the ACTUAL deadline?"
  1. Deadline: _______ (real / imagined)
  2. Deadline: _______ (real / imagined)
  3. Deadline: _______ (real / imagined)
  4. Deadline: _______ (real / imagined)
  5. Deadline: _______ (real / imagined)

☐ What's the ONE thing that, if not done today,
   causes real damage?
   _________________________________

☐ Do that one thing first. Ignore everything else
   until it's done.

☐ Then reassess. Repeat.
```
